# Repositorio de Prueba 🚀

¡Hola! Este es un repositorio de prueba creado con el propósito de experimentar con las funcionalidades de Git y GitHub, así como para practicar la estructura de directorios y archivos.

## 📄 ¿Qué contiene este repositorio?

Este es un entorno de pruebas ("sandbox") donde estaré subiendo y modificando distintos tipos de archivos. Actualmente incluye:

*   **Archivos de prueba:** Un par de documentos y/o scripts básicos para validar los *commits* y el control de versiones.
*   **Imágenes:** Elementos gráficos de prueba para verificar cómo se renderizan y visualizan los recursos multimedia dentro del repositorio.
