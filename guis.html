Taller: Diseño y Consultas SQL en MySQL

Objetivo: Comprender la estructura de una base de datos relacional y redactar consultas SQL (SELECT, INSERT, UPDATE, DELETE) basadas en un modelo de 4 tablas.

Contexto: Administramos la base de datos de una Feria Tecnológica para estudiantes de 3er Año. Tenemos Categorías, Proyectos, Estudiantes y las Evaluaciones de dichos proyectos.

Script de la Base de Datos (Estructura y Datos)

CREATE DATABASE FeriaTecnologica;
USE FeriaTecnologica;

CREATE TABLE Categorias (
    id_categoria INT PRIMARY KEY AUTO_INCREMENT,
    nombre_categoria VARCHAR(50),
    descripcion VARCHAR(100)
);

CREATE TABLE Proyectos (
    id_proyecto INT PRIMARY KEY AUTO_INCREMENT,
    titulo VARCHAR(100),
    fecha_presentacion DATE,
    id_categoria INT,
    FOREIGN KEY (id_categoria) REFERENCES Categorias(id_categoria)
);

CREATE TABLE Estudiantes (
    id_estudiante INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(50),
    apellido VARCHAR(50),
    nivel_academico VARCHAR(50)
);

CREATE TABLE Evaluaciones (
    id_evaluacion INT PRIMARY KEY AUTO_INCREMENT,
    id_proyecto INT,
    id_estudiante INT,
    calificacion DECIMAL(4,2),
    FOREIGN KEY (id_proyecto) REFERENCES Proyectos(id_proyecto),
    FOREIGN KEY (id_estudiante) REFERENCES Estudiantes(id_estudiante)
);
